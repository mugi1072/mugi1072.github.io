プライバシーポリシー

対象

このポリシーは、YouTube チャンネル「へぇチーン」（@heechiin）の運営者が使う個人用の投稿ツール「heechiin uploader」に適用されます。このツールは運営者本人のみが使い、ほかの利用者はいません。

使う情報

  • YouTube Data API を通じて、運営者自身の YouTube チャンネルに動画をアップロードし、タイトル・説明文・公開日時などを設定するための権限（youtube.upload）と、チャンネル情報を確認するための読み取り権限（youtube.readonly）を使います。
  • 運営者以外の YouTube ユーザーの情報は、取得・保存しません。

保存と共有

  • ログインのための認証情報（トークン）は、運営者の管理する環境の中だけに保存し、公開しません。
  • 取得した情報を第三者に販売・提供することはありません。
  • このツールによる YouTube の利用には、YouTube 利用規約とGoogle プライバシーポリシーが適用されます。

YouTube API サービスの利用について

このツールは YouTube API サービスを利用しています。利用にあたっては YouTube 利用規約に同意したものとみなされ、Google プライバシーポリシーが適用されます。

データの保存期間と削除

  • このツールが保存するのは、ログインのための認証情報（トークン）と、運営者がアップロードした動画の ID だけです。YouTube から取得したその他のデータは保存しません。
  • 保存した情報は、ツールの利用をやめたとき、または権限が取り消されたときに、7日以内に削除します。YouTube から取得したデータを保存する場合でも、30日を超えて保存しません。
  • このツールへの許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消すと、ツールは YouTube にアクセスできなくなります。
  • データの削除の依頼やお問い合わせは、こちら（GitHub Issues）から受け付けます。

English summary

"heechiin uploader" is a private tool used only by the owner of the YouTube channel "へぇチーン" (@heechiin). It uses the YouTube Data API (youtube.upload and youtube.readonly scopes) solely to upload and schedule the owner's own videos on the owner's own channel. It does not collect data from any other users. Access tokens are stored only in the owner's private environment and are never sold or shared. Use of YouTube through this tool is subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services; by using it you agree to the YouTube Terms of Service. Data retention and deletion: the tool stores only the OAuth token and the IDs of videos the owner uploaded. Stored data is deleted within 7 days after the tool stops being used or access is revoked, and no data obtained from YouTube is kept longer than 30 days. Deletion requests can be made via GitHub Issues.
