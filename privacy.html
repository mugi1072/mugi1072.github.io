プライバシーポリシー

対象

このポリシーは、YouTube チャンネル「へぇチーン」（@heechiin）の運営者が使う個人用の投稿ツール「heechiin uploader」に適用されます。このツールは運営者本人のみが使い、ほかの利用者はいません。

使う情報

  • YouTube Data API を通じて、運営者自身の YouTube チャンネルに動画をアップロードし、タイトル・説明文・公開日時などを設定するための権限（youtube.upload）と、チャンネル情報を確認するための読み取り権限（youtube.readonly）を使います。
  • 運営者自身のチャンネルの再生数・視聴維持率などの統計を確認するために、YouTube Analytics API の読み取り権限（yt-analytics.readonly）を使います。
  • 運営者自身の動画に付いたコメントを読み、運営者が確認した返信を投稿するために、youtube.force-ssl 権限を使います。視聴者のコメント（表示名・本文・いいね数・日時）は返信を考えるためだけに使います。
  • 動画づくりの研究のために、ほかのチャンネルの公開情報（チャンネル名・登録者数・動画のタイトル・再生数・公開コメントなど）を読むことがあります。ほかのユーザーの非公開の情報は取得しません。

保存と共有

  • ログインのための認証情報（トークン）は、運営者のパソコンと、運営者の非公開の GitHub リポジトリの暗号化された保存領域（GitHub Actions のシークレット）にだけ保存し、公開しません。
  • 定期的な投稿と集計は、運営者の非公開の GitHub リポジトリで GitHub Actions を使って自動で動かします。GitHub はこの処理と保存のためだけに使い、運営者以外は見られません。
  • 取得した情報を第三者に販売・提供することはありません。
  • このツールによる YouTube の利用には、YouTube 利用規約とGoogle プライバシーポリシーが適用されます。

YouTube API サービスの利用について

このツールは YouTube API サービスを利用しています。利用にあたっては YouTube 利用規約に同意したものとみなされ、Google プライバシーポリシーが適用されます。

データの保存期間と削除

  • このツールが運営者のパソコンに保存するのは、ログインのための認証情報（トークン）、運営者がアップロードした動画の ID とタイトルなどの投稿記録、運営者自身のチャンネルの統計、視聴者のコメントと返信案、研究のために読んだほかのチャンネルの公開情報です。
  • 運営者の非公開の GitHub リポジトリには、投稿記録と、運営者自身のチャンネルの統計をまとめたレポートを保存します。統計の元データと視聴者のコメントは、GitHub Actions の実行結果（Artifact）として保存し、25日で自動的に削除されます。
  • YouTube から取得した統計・コメント・ほかのチャンネルの公開情報の元データは、30日を超えて保存しません。運営者自身のチャンネルの統計をまとめたレポートは、運営者がこのツールへの許可を続けているあいだ保存します。
  • 保存した情報は、ツールの利用をやめたとき、または権限が取り消されたときに、7日以内に削除します。
  • このツールへの許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消すと、ツールは YouTube にアクセスできなくなります。
  • データの削除の依頼やお問い合わせは、こちら（GitHub Issues）から受け付けます。

English summary

"heechiin uploader" is a private tool used only by the owner of the YouTube channel "へぇチーン" (@heechiin). It uses the YouTube Data API and YouTube Analytics API (youtube.upload, youtube.readonly, yt-analytics.readonly and youtube.force-ssl scopes) solely to upload and schedule the owner's own videos, read the owner's own channel statistics, and reply (after the owner's review) to comments on the owner's own videos. Viewer comments (display name, text, like count and date) are used only to draft replies. For research on video making, it may also read public information about other channels (such as channel names, subscriber counts, video titles, view counts and public comments); it does not access other users' private data. Access tokens are stored only on the owner's PC and as an encrypted secret in the owner's private GitHub repository, and are never sold or shared. Scheduled uploads and reports run with GitHub Actions in that private repository, which only the owner can access. Use of YouTube through this tool is subject to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions. This tool uses YouTube API Services; by using it you agree to the YouTube Terms of Service. Data retention and deletion: the following are stored on the owner's PC: the OAuth token, a posting log (IDs and titles of videos the owner uploaded), the owner's own channel statistics, viewer comments with draft replies, and public information about other channels read for research. The owner's private GitHub repository stores the posting log and summary reports of the owner's own channel; raw statistics and viewer comments are kept there only as GitHub Actions artifacts, which are deleted automatically after 25 days. Raw statistics, comments and other channels' public information are not kept longer than 30 days; summary reports of the owner's own channel statistics are kept while the owner continues to authorize the tool. Stored data is deleted within 7 days after the tool stops being used or access is revoked. Deletion requests can be made via GitHub Issues.
